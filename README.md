# WellBot

Plateforme web pour aider les etudiants a suivre leur humeur, discuter avec un chatbot et trouver des ressources de bien-etre.

Projet integre - 2eme Licence Business Computing - BIS - Annee 2025/2026

---

## Fonctionnalites

- Inscription / Connexion securisee (mot de passe chiffre)
- Suivi quotidien de l'humeur (CRUD complet)
- Chatbot intelligent base sur Google Gemini (avec systeme de mots cles en secours)
- Bibliotheque de ressources de bien-etre
- Statistiques et graphiques d'evolution de l'humeur
- Espace administrateur (gestion des utilisateurs et des ressources)

## Technologies

- **Back-end** : PHP 8.1 + Laravel 10
- **Front-end** : Bootstrap 5 + Chart.js
- **Base de donnees** : SQLite (par defaut) ou MySQL via phpMyAdmin
- **IA** : API Google Gemini (gratuit)
